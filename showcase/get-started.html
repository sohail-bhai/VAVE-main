Before you begin.

Windows 10 / 11

Primary target. Some integrations are Windows-specific.

Python 3.11 recommended

64-bit Python. Enable “Add Python to PATH” during installation.

Ollama + a local model

Choose a model that fits your available RAM/VRAM.

Internet for first setup

Dependencies and models download separately. Models can be several GB.

Get Python and Ollama from their official websites.

Three steps to your desktop.

1

Extract and install.

Extract the ZIP. Open its VAVE folder, then double-click Setup_VAVE.bat. Keep the console open for installation results. Or use PowerShell in that folder:

PowerShell / install
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
2

Connect a local model.

Start Ollama, then pull and check the example model below. Choose a smaller model if needed; update VAVE’s model settings to match what you installed.

PowerShell / local AI
ollama pull qwen2.5:7b
ollama list
ollama run qwen2.5:7b "Reply with ready."
Source package uses Ollama’s default model folder. For another existing folder, set Settings → AI Helpers → Model directory. A development-machine path may be saved in a clone; choose your own path before loading models.
3

Launch VAVE.

Double-click Start_VAVE.bat, or launch from PowerShell:

PowerShell / launch
.\.venv\Scripts\python.exe vave_gui.py

Start with typed input. Voice listening stays under your control. For browser automation, install Chromium separately:

PowerShell / optional browser tools
.\.venv\Scripts\python.exe -m playwright install chromium

Start small. See what happens.

Run the safe smoke checks first. They stub browser, app, volume, screenshot, and destructive side effects.

PowerShell / safe checks
.\.venv\Scripts\python.exe main.py --smoke-test
.\.venv\Scripts\python.exe main.py --text "time" --no-speech

A few useful answers.

Do I need a microphone?

No. Use typed commands in the desktop dashboard or the one-shot text CLI. Voice requires suitable input hardware; Google speech recognition can also need the internet.

Ollama is running, but VAVE can’t find my model.

Check ollama list and confirm VAVE’s model name matches exactly. In Settings → AI Helpers, check the model directory. If you change Ollama’s storage path, restart Ollama before checking again. Keep existing model files; see the runtime readiness roadmap for the development machine’s documented manifest issue.

Dependency installation fails.

Read the error shown by Setup_VAVE.bat. Use 64-bit Python 3.11 and an updated pip. PyAudio can be difficult on Windows; check the README troubleshooting for supported setup options. Don’t continue launching until dependency installation succeeds.

Can I use macOS or Linux?

Some core functions and system actions have cross-platform support, but desktop automation and several integrations remain Windows-specific. This quickstart targets Windows; full feature parity is not claimed.

Is everything offline?

The default AI brain runs through local Ollama. Browser work and connected services use the network. Google speech recognition is online. Optional hosted AI configurations also send requests to their configured provider.

Is there a one-click installer?

This release contains source and setup/launch scripts. Python, dependencies, Ollama, and models are separate prerequisites. A standalone signed installer is future packaging work.

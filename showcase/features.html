How work moves

From “can you…”
to a visible result.

Try the illustrative walkthrough
  1. 01

    State the goal.

    Enter a typed request, use optional voice, or send a request through a paired client. Coordination belongs in the service layer.

  2. 02

    Create bounded steps.

    The control plane plans work and stores task state. The executor sends each step to the AI agent with its relevant context.

  3. 03

    Check permission.

    Capabilities and policy determine whether an action is allowed, denied, or held for human approval. Credentials resolve inside the control plane.

  4. 04

    Use the right tools.

    The agent calls desktop, browser, file, or service tools. Execution can check cancellation between calls; a call already running may finish first.

  5. 05

    Return the evidence.

    Tool results, task state, and activity events make work observable. Failures and approval holds remain visible instead of being treated as completed work.

An honest snapshot

Built today.
Growing tomorrow.

VAVE is an actively developed desktop project. Broader autonomy is governed by a phased roadmap and acceptance gates.

Implemented foundation

  • Ollama agent loop and tool registry
  • Desktop dashboard and typed commands
  • Tasks, policy, approvals, and cancellation
  • Browser tools, memory, and service integrations
  • Guard, credential store, and audit layer

Practical limits & next steps

  • Local AI needs a working Ollama model
  • Windows is the primary desktop target
  • Workspace and phone features need setup
  • Long-running calls stop between tool calls
  • Runtime readiness and deeper verified autonomy remain roadmap work
Local-first describes the AI core. Browser actions, cloud integrations, and Google speech recognition can use the network. Explore the roadmap
